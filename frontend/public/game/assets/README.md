# Assets do IFC Sombrio

## Sprites de personagens
Adicione PNGs com nomes:
- puskas.png, dana.png, mello.png, tony.png, rosa.png,
- rafa.png, bia.png, kevin.png, leo.png, luna.png

Tamanho recomendado: 32x32 ou 64x64 pixel-art. O jogo escala automaticamente.
Se um arquivo não existir, o jogo gera um sprite por canvas.

## Sons (assets/sfx/)
Adicione MP3s opcionais para sobrepor os SFX gerados:
- hit.mp3, crit.mp3, miss.mp3, heal.mp3, buff.mp3, debuff.mp3,
- menu.mp3, victory.mp3, defeat.mp3, levelup.mp3
